## 4. 网络/代理注意事项

- 用户机器开启了 **TUN 模式**，因此一般**不需要**设置 `http_proxy/https_proxy`。
- 如果之前设置了代理环境变量，请先清除：

```bash
unset http_proxy https_proxy
```

- 如果后续某个下载失败并出现 `Failed to connect ... via 127.0.0.1`，说明代理端口配置错误，
  需要确认 Clash/Mihomo 的 HTTP 端口，或直接走 TUN。
- 如果出现 GitLab 下载 429，需要在代理规则中加：

```yaml
- DOMAIN-SUFFIX,gitlab.dkrz.de,PROXY
```

## 4.1 下载失败时手动放置源码包

vcpkg 的下载缓存目录是：

```text
$VCPKG_ROOT/downloads/
```

也就是：

```text
/home/jamesyasr/dsh-workspace/vcpkg/downloads/
```

如果某个端口下载失败，例如 `glew-2.2.0.tgz`、`HDFGroup-hdf5-*.tar.gz`，可以手动下载后放到这个目录。

操作步骤：

1. 从报错日志或对应 `portfile.cmake` 中找到：
   - 下载 URL
   - `FILENAME`
   - `SHA512`
2. 用浏览器或 curl 下载，并重命名为日志中的 `FILENAME`。
3. 放到 `$VCPKG_ROOT/downloads/`。
4. 校验哈希：

```bash
sha512sum /home/jamesyasr/dsh-workspace/vcpkg/downloads/<FILENAME>
```

5. 哈希必须与 `portfile.cmake` 中的 `SHA512` 完全一致。
6. 重新跑构建命令，vcpkg 检测到文件已存在且哈希正确，就不会再联网下载。

注意：

- 文件名必须严格一致，例如 `glew-2.2.0.tgz`，不能改名成别的。
- 如果某个包是通过 `vcpkg_from_git` 拉取的（例如 VTK），vcpkg 会自己生成缓存包，不需要手动放 tar 包；只需确保能访问 GitHub 或 TUN 正常。
- 如果代理规则导致 GitLab 下载 429，可以加规则：
  ```yaml
  - DOMAIN-SUFFIX,gitlab.dkrz.de,PROXY
  ```

## 5. 构建命令

```bash
cd /home/jamesyasr/dsh-workspace/CloudForge-Analyzer

export VCPKG_ROOT=/home/jamesyasr/dsh-workspace/vcpkg
export VCPKG_MAX_CONCURRENCY=16

taskset -c 0-15 cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_TOOLCHAIN_FILE="$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake" \
  -DVCPKG_TARGET_TRIPLET=x64-linux \
  -DVCPKG_OVERLAY_PORTS="$PWD/vcpkg-ports" \
  -DVCPKG_OVERLAY_TRIPLETS="$PWD/vcpkg-triplets"

taskset -c 0-15 cmake --build build --parallel 16
```

说明：

- `VCPKG_MAX_CONCURRENCY=16` 限制 vcpkg 并行编译数。
- `taskset -c 0-15` 强制只使用 16 个 CPU，防止 32 线程全开导致内存溢出。
- `VCPKG_OVERLAY_PORTS` 和 `VCPKG_OVERLAY_TRIPLETS` 必须传，否则 VTK 9.3.0 overlay 不生效。
- 如果改了依赖清单，建议先 `rm -rf build` 再重新配置；如果只是继续断点，不需要删。

## 7. 常见报错速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Could not find bison` | 缺少 bison | `sudo apt install bison flex` |
| `libb2 requires autoconf` | 缺少 autoconf/automake/libtool | `sudo apt install autoconf automake libtool` |
| CMake 4 报 `Compatibility with CMake < 3.5` | 旧端口不兼容 CMake 4 | 已通过 overlay triplet 传 `CMAKE_POLICY_VERSION_MINIMUM=3.5` |
| `uint32_t has not been declared` | GCC 15 太新，旧代码缺 `<cstdint>` | 已通过 `-include cstdint` 全局解决 |
| `vcpkg_from_git` 报 REF 必须是 SHA | tag 不能直接作为 REF | 已改为 commit SHA + `FETCH_REF` |
| VTK 配置报 `Could NOT find OGG/NetCDF/LibPROJ/LibHaru` | 禁用的模块名不对或模块仍被组启用 | 已逐步加 `DONT_WANT` 和上游补丁 |
| VTK 编译报 `_M_chilren` | VTK 9.3.0 老代码依赖 GCC 内部命名 | 已加 `fix-octree-gcc15.patch` |
| 下载 429 | GitLab/源站限流 | 加代理规则或手动下载到 `$VCPKG_ROOT/downloads/` |
| 内存不足/卡死 | 32 线程全开 | 使用 `VCPKG_MAX_CONCURRENCY=16` + `taskset -c 0-15` |
