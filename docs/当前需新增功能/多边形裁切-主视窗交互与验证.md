# 多边形裁切：主视窗交互与验证

## 操作

点击侧边栏“裁剪”后，在主窗口左侧显示 Qt 停靠面板。选择点云，单击添加顶点，点击起点或“闭合轮廓”完成描边。闭合后可拖动顶点、点击边线插入顶点，右键顶点可删除；“撤回”恢复上一步轮廓修改，“重画”重新开始。

“调整视角”使用原有旋转、平移和缩放，完成后切回“绘制轮廓”。面板可通过 Qt 标题栏拖动、浮动或重新停靠到主窗口左右两侧，轮廓可隐藏。选择“保留框内”“保留框外”或“分成两份”，点击“预览裁切”，框内显示绿色，框外显示淡红色；分成两份时框外显示橙色。面板显示两侧点数，应用后沿用主界面撤销/重做。取消或关闭面板始终恢复原点云显示。

全部操作可用鼠标完成。保留快捷键：X 切换绘制/视角，Enter/右键闭合，R 重画，C 预览，S 显示/隐藏轮廓，Q/Esc 退出；增加 Backspace/Ctrl+Z 撤回轮廓编辑。裁切期间 Ctrl+Z 不触发点云撤销。

裁切是当前视角下的贯穿选区，同一屏幕位置的前后点一起分类，不是只选择最前面的可见表面。

## 架构与安全边界

- `CloudClipper` 只进行投影与多边形分类，无 Qt/VTK 依赖。GUI 线程捕获相机、视口与点云 actor 的组合变换，后台计算返回共享结果，保留源点坐标、次序及传感器信息。
- `PolygonClipTool` 管理 Qt 轮廓叠层、QDockWidget 操作面板与临时 VTK 预览图元，沿用现有主窗口。浮动仅针对操作控件，不创建额外查看器；没有外部 PCL 窗口、嵌套循环或裁切缓存文件，不替换 VTK 交互器、交互样式或拾取器。
- 构造阶段不提前访问主相机，不改变启动自动取景。预览图元不可拾取、不参与相机包围盒；取消移除图元并还原源 actor 可见性。源 actor 变换、点大小和透明度应用到裁切结果。
- 主窗口沿用 `RunAsyncVoid`、进度和取消机制；后台不触碰查看器、Qt、VTK、点云表或撤销记录。退出、切换操作和修改点云时清理控制器；序号防止取消后的迟到结果进入界面。
- 修改轮廓、调整视角、改变视窗大小会使预览失效，应用前再次核对投影。自交、退化轮廓不能预览；空保留区不能应用，分成两份要求两侧均有点。
- 应用前检查源点云仍为原对象。先建立撤销批次，再删除源点云并添加结果，保证一次撤销恢复完整源点云。旧流程在建立撤销批次之前删除源点云，这一顺序已修正。

旧流程存在独立窗口、回调及磁盘缓存的生命周期风险，本次整体替换这条路径。没有取得旧版确认崩溃时的调用栈，因此不把某一个推测写成已证实的唯一崩溃根因。

## 算法对照

1000 个已知投影点与旧版射线法逐点对照：避开边界的正常前方点分类、坐标和顺序一致。明确调整的行为：

1. 轮廓边界上的点统一归入框内，顺/逆时针一致。
2. 相机后方、视锥外及非有限坐标点归入框外，防止投影折返误选；框内与框外合计仍等于输入点数。
3. 自交、相邻重合和零面积轮廓拒绝预览，界面提示调整轮廓。
