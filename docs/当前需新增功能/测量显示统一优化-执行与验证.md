## 3. 弧长

- 圆柱弧长与测地线使用同一原生 Qt 停靠面板，字体、表单、分组和直角按钮沿用高度测量窗口，可拖动浮动。只有凹坑窗口隐藏不需调整的固定参数；弧长当前拟合方式的全部可调参数直接显示，不折叠。
- 保持点云、已保存参考圆柱、拟合方式、中线或选点位置的逻辑顺序；测地线保留邻域半径与原两点拾取顺序。所有默认值沿用旧窗口，未改变算法。
- 单个选项自动选中，多个选项要求明确选择，不根据名称猜测。圆柱编号保持简洁。
- 曲线使用亮青色 / 金色主线与深色衬线、屏幕端点及统一直角结果卡片。两个共享原相机的前景显示层分别绘制衬线与主线，避免衬线自身遮挡亮线。曲线坐标完全沿用计算结果，相机及交互器不替换。
- 面板支持开始、取消、清除结果、关闭及 Ctrl+Enter；选点时 Esc 取消选点。关闭保留已完成结果，但取消未完成的选点或计算；过期异步回调不再生成结果。
