# 视窗结果标注：统一组件与清理

实施日期：2026-10-22。状态：已实现，正常显示与额外两倍缩放的桌面验证通过。

## 范围

将焊前装配左上角图例的风格固化为 `Basic/ViewportResultOverlay`：Qt QWidget，深色底、直角细边框、中文、逻辑像素字号，图例使用水平色样，结果数值加粗，不添加装饰竖条。不改测量算法、依赖版本、CMakeLists 或报告精度。

组件按字符串标识维护多个结果区，支持新增、替换、单项删除和全部清除；多个结果自动纵向排列。窄视窗的图例改为单列，长结果行改为上下排列。显示不参与鼠标拾取，不访问相机，不主动驱动 VTK 渲染；可以避让正在显示的操作提示。

主窗口持有一个通用组件。`WeldPreparationOverlay` 保留空间锚点、引线、端点和投影布局，只向通用组件提供焊前图例，并在空间标签排布时避让整个固定结果区。计算类没有新增 Qt 依赖。

## 已接入的显示

| 功能 | 原显示 | 本次处理 |
|---|---|---|
| 焊前装配 | 专用 Qt 叠层内硬编码的图例 | 图例内容交给通用组件；空间标签仍跟随极值位置 |
| 测地线弧长 | 主视窗启用路径，旧 VTK 英文长度文字关闭 | 通用组件显示曲面路径长度，三位小数、mm；复测替换 |
| 圆柱弧长 | 主视窗画曲线，结果只进报告 | 通用组件显示截面弧长；当前曲线和结果一起替换，避免旧曲线与最新数值混淆 |
| 高度测量 | 独立 PCL 窗口内的英文固定统计文字 | 保留独立窗口，以 Qt 容纳原三维内容，通用组件显示最大、最小、平均高度 |

高度窗口保留 Q 关闭快捷键，由自身关闭动作释放，三维相机及交互由原 PCL/VTK 处理，不再需要手动轮询窗口。显示单位沿用主程序测量约定 mm，计算值不换算。

## 清理规则

清理按显示用途进行，不要求用户区分 Qt 或 VTK。沿用既有菜单，不新增“清除 Qt”入口。

| 入口 | 文字 / 图例 | 对应三维内容 |
|---|---|---|
| 清除二维演示 | 清除所有主视窗结果区、焊前屏幕标签及图例、原有 VTK 色标 | 保留路径与模型，符合二维清理含义 |
| 清除几何 | 清除测地线、圆柱弧长、焊前结果及两点测距标注 | 同步清除对应路径、曲线、尺寸及原有形状 |
| 清除测地线 | 只删除测地线结果区 | 只删除原测地线对象，保留其他测量结果 |
| 全部清除 | 不留下主视窗 Qt 结果 | 沿用现有全部清理流程移除 VTK / PCL 显示 |
| 点云增删、清空、撤销恢复 | 使上述关联测量结果失效 | 同步移除其测地路径、圆柱弧线和焊前尺寸，避免旧结果挂在新数据上 |
| 统一 actor 清理 | 删除圆柱弧长结果和焊前标签 | 删除它们已有的受管 actor；测地线仍由自己的清理入口管理 |

`cleanGeodesicVisualization`、`cleanArcMeasurement`、`cleanWeldPrepVisuals` 是各功能图形与结果的成对清理入口；这些入口同时处理结果区和对应三维对象。二维清理只移除标注，随后重新测量可正常恢复。

## 其他结果显示盘点

以下显示承担空间定位或连续数值映射，不适合直接变成固定角落文字，保留原用途：

- 两点测距：VTK billboard 标注端点与空间长度，属于交互工具的空间标签。
- 凹塘：PCL `addText3D` 的逐坑、最大距离与引线标签，位置与被测部位关联。
- 焊缝高度：最大位置的 PCL 三维文字与标记。
- 平面度、圆柱度、焊缝高度：VTK scalar bar，保留连续颜色与数值刻度。
- 状态栏、报告框和操作提示：不属于视窗结果区。

测地线计算类原来的 `createTextActor` 保留为兼容的 VTK 展示接口，主程序使用通用 Qt 组件，不启用该旧文字。此次不进行全局渲染管理或计算类重构。
