# 点云选择窗口：共享视图点选

日期：2026-11-08。常规功能，进入 `master`。

## 使用

点云簇管理、另存为、测量/拟合等点云选择窗口右上角提供“视图点选”。开启后：

- 点击可视化中的点云，切换其对应复选框；再次点击取消，可选择多个点云。
- 列表勾选、全选、清空与黄色包围框同步；边框只用于当前选择窗口，不改变点云颜色和数据。
- 空白处不改变选择，隐藏或完全透明的点云不参与视图点选。
- 拖动旋转、滚轮缩放保留；拖动不触发选中。
- “结束点选”或视图内 Esc 停止点选并保留勾选，窗口原有确认/取消、保留/删除规则继续生效。
- 关闭选择窗口恢复光标和主窗口操作；关闭主窗口会取消当前选择窗口。

## 复用方式

- 按钮、勾选同步、同步返回流程集中在父类 `CloudSelectionDialog`。
- `ViewportCloudSelector` 是主窗口提供的 GUI 线程服务，读取点云标识与 actor 的对应关系，只允许当前对话框已有的点云参与选择。
- 新的点云选择窗口继承 `CloudSelectionDialog`，构造时传入主窗口 `parent`，使用其虚拟 `exec()`，无需另写点选逻辑。
- 没有可视化服务的独立对话框继续使用普通 Qt 模态流程，视图按钮禁用。
- 由于原有派生类和业务入口同步取回结果，父类保留同步返回约定；使用非模态窗口加局部事件循环，仅在点选模式开放主视图交互，同时禁用主窗口动作、拦截其它编辑输入，防止选择期间场景改变。
- `Hide` 事件可能来自窗口系统的临时取消映射或最小化；仅在 QWidget 真正隐藏时结束循环，避免将临时隐藏误认为操作结束。相关 Qt 行为参见 [Qt 6.7.3 QDialog 实现](https://github.com/qt/qtbase/blob/v6.7.3/src/widgets/dialogs/qdialog.cpp)。
