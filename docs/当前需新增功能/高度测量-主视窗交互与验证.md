# 高度测量：主视窗交互与验证

## 范围

本轮改造普通高度测量，不涉及焊缝高度。原有测量点云到拟合参考平面的距离定义、迭代邻域平均方式和默认参数（邻近点 10、测量次数 5）保留。

删除独立高度 VTK 窗口及旧 ParamDialogMeasureHeight，改为主窗口侧边 Qt 停靠面板，可拖动、浮动和关闭。没有文件缓存或重新加载，不替换主视窗交互器，不重设相机。

## 操作与显示

从侧边栏高度按钮进入，直接选择测量点云、参考面点云和参数，点击开始测量。计算期间冻结输入，按钮显示计算/取消状态，沿用主窗口进度条及取消入口。支持面板按钮、Ctrl+Enter 开始、Esc 结束，以及主视窗 Q 结束。

面板顶部直接从点云选择开始，不设置完成、计算、取消或失败状态文字行。取消和失败消息输出到右侧结果区与日志；成功结果附带“绿色低、红色高；黄色线表示最大高度”的显示说明。面板保持数值摘要、各次平均高度表、显示开关、清除及结束按钮。

主视窗显示原点云的高度颜色、拟合参考平面、辅助法向高度线和黄色最大高度尺寸。倾斜参考面的尺寸沿拟合面法向投影，不能用 Z 坐标差代替。最大、最小、平均高度使用共享 ViewportResultOverlay 直角结果面板。

高度着色关闭时恢复原点云显示。清除结果、结束、关闭、删除源点云、撤销重建和几何/RGB/全部清理均回收本工具拥有的图形与标签并恢复原显示状态。2D 清理仅移除结果标注，保留几何。点云数据、颜色表和撤销数据不写入测量临时结果。

## 实现边界

- HeightMeasureTool 管理停靠面板、临时 actor、显示快照与结果生命周期。
- CloudForgeAnalyzer 调度现有异步任务，GUI 线程建立和清除 Qt/VTK 显示。
- MeasureHeight 保持纯计算，补充可取消进度回调与原颜色映射的点云输出。计算线程不访问 Qt/VTK。
- 每次请求携带序号，关闭或清除后丢弃迟到结果，避免重新创建失效显示。
- 原独立窗口的通用标注测试移出 analysis/viewport_results，改由本功能独立验证覆盖。

## 验证方式

旧版基线取自 6969631 的 MeasureHeight，保存于 analysis/height_measurement/baseline_6969631.txt。五组固定样本覆盖水平、变化高度、倾斜参考面、共面与参考面另一侧；以十六进制浮点表示比较最大/最小/平均高度、参考面系数、五次平均值，并比较原颜色字节哈希。不得用新版结果覆盖旧版基线。

```bash
analysis/run_guarded.sh analysis/height_measurement/build_test.sh
analysis/run_guarded.sh env QT_QPA_PLATFORM=xcb OMP_NUM_THREADS=2 ./build/test_height
analysis/run_guarded.sh env QT_QPA_PLATFORM=xcb QT_SCALE_FACTOR=2 HEIGHT_CAPTURE_SUFFIX=_2x OMP_NUM_THREADS=2 ./build/test_height
```

串行执行，构建最多两个任务，由既有资源保护脚本限制内存。桌面测试直接操作主窗口控件，覆盖计算、旋转、显示切换、重复测量、停靠浮动、快捷键、取消、清理、输入失败、迟到结果、退出与空闲渲染。

截图保存在 analysis/height_measurement/main_result*.png、floating_controls*.png、tilted_result*.png。日志位于 build/height_test_build.log、height_gui.log、height_gui_2x.log。

本轮不运行其他功能回归；Windows 尚未验证。没有改变科学结论或 PPT 业务内容，未重新生成演示稿；新截图可用于后续替换界面素材。

## 本轮实测结果（2026-10-22）

- 主程序及独立高度验证程序构建成功。
- Linux 桌面普通缩放和额外两倍缩放均 pass=67 fail=0。
- 五组样本的高度统计、参考平面系数、迭代平均值及 RGB 哈希与旧基线逐位一致。
- 已查看主视窗结果截图：左侧顶部没有任何状态提示行，右侧结果包含颜色说明；三维高度图、黄色最大高度线和共享数值标注清晰。
- 鼠标操作显示开关及主视窗旋转、重复计算、浮动后 Esc 退出、取消、删除/撤销、各类清理与空闲渲染检查通过。
