# 平面拟合异常点排除：性能调查

2026-10-22，以下是基于 abcb29d 的初始调查记录。后续用户授权在难以大幅优化时移除局部预处理，最终已移除并优化全局结果提取。最终实现与验证见 docs/当前需新增功能/平面拟合-移除局部预处理与性能优化.md。初始记录中的“当前”均指调查时旧版。

## 结论

当前耗时有两个独立来源：

1. Fit_Plane::detectAnomalyPoints 对每个输入点做不限数量的半径搜索，复制邻域点云，新建 SACSegmentation，执行局部 RANSAC 和系数优化。相邻点的邻域大量重叠，重复工作随点数及局部密度增长。半径搜索默认排序结果，循环中还有反复分配开销，但这些不是唯一瓶颈。
2. Fit_Plane::fitPlaneWithRANSAC 在全局拟合后，对每个保留点使用 std::find 扫描全部内点索引。复杂度为 O(N × I)，多数点为内点时接近 O(N²)。关闭异常点检测不能避开此瓶颈。

附带问题：Fit_Plane 没有进度/取消回调。主窗口只在 compute 前检查一次取消，计算后丢弃取消的结果；耗时循环仍继续运行。界面的最大迭代次数只传给全局 RANSAC，局部 SACSegmentation 仍使用锁定 PCL 1.14.0 的默认上限 50；减小界面迭代次数不能直接减少逐点局部拟合的上限。

## 计时

同一原始 Debug 对象，固定轻微波动平面，单位秒。默认局部半径 5 mm，异常阈值 1 mm，全局拟合阈值 1 mm。分段直接调用原始函数。

| 点数 | 点间距 | 异常检测 | 全局 RANSAC 单独 | 原全局拟合及外点提取 |
| --- | --- | --- | --- | --- |
| 10,000 | 0.5 mm | 4.173 | 0.006 | 0.107 |
| 40,000 | 0.5 mm | 17.353 | 0.023 | 1.637 |
| 10,000 | 0.25 mm | 15.797 | 0.006 | 0.108 |

关闭局部检测，2,500 / 10,000 / 40,000 点的原全局拟合及外点提取分别约 0.010 / 0.133 / 1.673 秒。40,000 点时，使用相同内点索引的简单标记数组补集构造约 0.0003 秒。这里只比较索引处理的工作量，不代表整个拟合能得到相同比例的加速；此探针只核对两次 RANSAC 的分类数量，不能替代未来算法修改所需的完整输出基线。

密度案例中抽样平均邻居数约 279 增至 1,037，与局部检测耗时增加相符。所有八次探针成功退出，每次峰值 RSS 低于 45 MiB。原始摘要见 perf_results.txt，完整临时日志为 build/plane_perf.log。

这是单次、本机 Debug、合成样本调查，不代表 Windows Release 实际耗时，也未外推百万点绝对用时。

## 异常点分类的边界

当前“异常”指相对局部拟合平面的偏离，和最终目标平面的外点不同。邻居不足或局部拟合失败时，当前实现保留该点。

探针每 31 点加入一个抬高点：抬高 3 mm 时 323 点被局部检测排除；抬高 10 mm 时局部检测未排除这些点，最后由全局拟合将其列为 323 个外点。这不能说明最终平面错误，但说明该预处理的收益取决于噪声分布，不能将其视为通用异常点清理。

## 建议次序

先以完整旧输出建立基线，将外点索引补集改为线性标记并加入计算进度与取消，同时减少临时分配。此阶段应逐项保证平面系数、内点/外点/异常点索引及次序不变。

再单独处理局部检测：考虑复用空间分块/邻域模型、限制用于估计局部面的代表点，或采用稳健局部协方差拟合并对困难邻域回退 RANSAC。任何减少采样或更换局部模型的方案都可能改变异常点分类，需要基于实际平面样本与注入异常点逐条比较，不能承诺与原算法逐位一致。暂不直接用全局 RANSAC 替代局部检测，以免未经确认改变功能含义。

## 复现

```bash
analysis/run_guarded.sh analysis/plane_fitting/build_probe.sh
analysis/run_guarded.sh env OMP_NUM_THREADS=2 taskset -c 0-1 timeout 45 ./build/plane_perf_probe 100 .5 0
```

当前探针参数依次为方形网格边长点数、点间距、每 31 点的抬高量。默认比较旧版完整流程与新版；追加 --new-only 只测新版。--delta 则输出 18 组样本相对旧默认流程的数值与分类差异。程序不弹对话框、不运行主窗口。初始分段计时保存在 perf_results.txt，最终对照保存在 perf_results_final.txt。
